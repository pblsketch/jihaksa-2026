## 1. 왜 다시 만들었나

Apps Script에서 실시간이 안 됐던 건 설정 문제가 아니라 구조 문제였습니다.

| | Apps Script | 지금 |
|---|---|---|

## 2. 설치 — 딱 한 번만 하면 됩니다

**셋 다 이미 끝나 있습니다.** 아래는 나중에 다시 만들 일이 생겼을 때를 위한 기록입니다.

### ① Supabase 스키마 — 적용 완료

`supabase/schema.sql` 을 SQL Editor에 붙여넣고 Run 하면 됩니다.
Personal Access Token이 있으면 명령으로도 됩니다.

```bash
SUPABASE_PAT=sbp_... node supabase/apply.mjs
node supabase/verify.mjs     # 15개 항목 점검
node supabase/e2e.mjs        # 서버 로직 44개 항목 검증 (끝나면 기록을 지웁니다)
node supabase/e2e.mjs --seed # 현황판 확인용 12명분 가짜 데이터 생성
```

> ⚠ `schema.sql` 은 다시 실행하면 **응답이 모두 지워집니다.** 연수 당일에는 절대 다시 실행하지 마세요.
> 리허설 기록만 지우려면 관리자 화면의 「응답 모두 비우기」를 쓰세요.

### ② Realtime — 켜짐 확인 완료

**Database → Replication → `supabase_realtime`** 에 5개가 들어 있습니다.
`participants` · `ox_responses` · `practice_responses` · `sentences` · `settings`

### ③ 배포 — GitHub Pages 완료

저장소 `pblsketch/jihaksa-2026`, `main` 브랜치 루트. `git push` 하면 1분 안에 반영됩니다.

### 진행 순서

1. 처음에는 4개 과제가 **모두 닫혀** 있습니다
2. 오른쪽 위 **「모니터에 띄우기」** 에서 지금 할 활동의 현황판을 새 탭으로 엽니다 → 모니터로 보내고 `F` 로 전체화면
3. 활동을 시작할 때 그 과제 카드의 **스위치를 켭니다**
   → 선생님들 화면이 **저절로** 바뀝니다. "새로고침하세요" 안내가 필요 없습니다
4. 카드의 숫자(`9 / 15명`)와 막대를 보면서 **언제 넘어갈지** 판단합니다
5. 활동이 끝나면 스위치를 꺼도 되고, 켜 둔 채로 다음으로 넘어가도 됩니다

| 스위치 | 하는 일 |
|---|---|
| ① O·X 퀴즈 | 퀴즈를 열고 닫습니다 |
| ② 실습 A · 나의 미래 일기 | 실습 A를 열고 닫습니다 |
| ③ 실습 B · 학술 연구 포스터 | 실습 B를 열고 닫습니다 |
| ④ 오늘의 한 문장 | 문장 활동을 열고 닫습니다 |
| OX 정답 공개 | 켜면 참가자 화면·현황판에 **정답과 방송 패널 성적표**가 동시에 뜹니다 |
| 자료 전체 공개 | 켜면 과제를 다 안 해도 자료가 열립니다 (강제 공개) |
| 실습 A·B 둘 다 필수 | **기본 꺼짐** — A 또는 B 하나만 내도 자료가 열립니다 |

### 「지금 들어온 응답」 패널

모니터에는 현황판(그래프·히트맵)이 나가지만, **선생님 응답의 원문**은 여기서 봅니다.
강의 중에 "○○ 선생님은 이렇게 쓰셨네요" 하고 짚으실 때 쓰는 자리입니다.

- **한 문장** — 제출된 문장 전문이 최신순으로 쌓입니다
- **실습 A / B** — 사람별로 `항목 · 위험(상중하) · 허용단계 · 장치 한 줄` 이 그대로 보입니다

> 화면이 좁으면(노트북 1150px 미만) 3단이 2단 → 1단으로 접힙니다. 태블릿·휴대폰으로 열어도 동작은 같습니다.

### 현황판 4종 (모니터용)

`← →` 키로 화면을 넘기고 `F` 로 전체화면이 됩니다.

| 화면 | 무엇을 보여주나 | 이야기 소재 |
|---|---|---|
| ① O·X 퀴즈 | 문항별 O/X 큰 막대 + 실시간 인원. 정답을 켜면 정답 테두리와 패널 성적표가 붙습니다 | "가장 문학적인 문장에 사람이 몰렸는데, 그게 AI였습니다" |
| ② 실습 A | 활동 9개 × 허용 단계 5개 **히트맵**. 색이 진할수록 그 단계에 몰린 것. 오른쪽은 외주화 위험 상·중·하 분포 | **「판단 갈림」 배지**가 붙은 활동 — 과반이 없는 곳이 토론거리입니다 |
| ③ 실습 B | 활동 7개로 동일 | 위와 같음 |
| ④ 한 문장 | 문장 카드가 3열로 쌓이고, **새 문장은 노란 테두리로 떨어집니다** | 마지막 장면용 |
| 제출 현황 | 과제별 제출 게이지 4개 + 참가자 이름 칩 (점 4개 = OX·A·B·문장) | 다음 활동으로 넘어갈 타이밍 판단 |

### 자료 공개

- 자동 — **OX + 실습(A 또는 B) + 문장**을 모두 낸 분에게 자료 메뉴가 열립니다
- 수동 — 「자료 전체 공개」를 켜면 누구에게나 열립니다 (마무리 때 켜시면 됩니다)

## 4. 알아 두시면 좋은 것

- **입력 중이던 실습 내용은 기기에 자동 저장됩니다.** 과제가 닫혔다 열려도, 화면을 껐다 켜도 남아 있습니다.
- **다시 제출할 수 있습니다.** 같은 과제를 다시 내면 이전 것을 덮어씁니다 (사람별 1건).
- **이름으로 이어하기** — 중간에 나갔다 같은 이름으로 들어오면 이어집니다. 동명이인은 「새로 시작」을 고르면 별개로 잡힙니다.
- **OX 정답은 서버에만 있습니다.** 「정답 공개」를 켜기 전에는 브라우저 개발자 도구를 열어도 안 보입니다.
- **쓰기는 전부 서버 함수(RPC)를 통과합니다.** 프론트에 있는 publishable key로는 남의 응답을 고치거나 지울 수 없습니다.
- **닫힌 과제는 서버가 거부합니다.** URL을 직접 쳐서 들어가도 제출이 안 됩니다.

## 4-1. 교과서 보기 (실습 A · B)

실습지의 각 문항 옆에 **「○○쪽 교과서 보기」** 버튼이 있습니다. 누르면 그 쪽이 전체 화면으로 펼쳐집니다.

- **실습 입력은 그대로 남습니다.** 화면을 갈아 끼우지 않고 위에 덮어 띄우기 때문에, 닫으면 보던 문항 그 자리로 돌아옵니다.
- **확대** — 오른쪽 위 버튼으로 100 → 200 → 320%. 화면을 **두 번 톡 치면** 그 지점 기준으로 바로 크게 볼 수 있습니다.
- **쪽 넘김** — 아래 「이전 쪽 / 다음 쪽」, 또는 축소 상태에서 좌우로 밀기.
- **닫기** — 왼쪽 위 ✕, 또는 안드로이드 뒤로가기.
- 실습지 위쪽의 「해당 쪽 펼쳐 보기」로 그 교과서의 관련 쪽 전체를 훑을 수도 있습니다.
- 한 번 열면 그 실습지의 나머지 쪽을 미리 받아 둡니다. 연수장 와이파이가 느려도 두 번째부터는 즉시 뜹니다.

**들어 있는 쪽**

| 실습 | 교과서 | 쪽 |
|---|---|---|
| A | 독서 토론과 글쓰기 | 80 · 81 · 82 · 91 · 92 · 93 |
| B | 주제 탐구 독서 | 215 · 216 · 217 · 218 · 219 |

**이미지를 다시 굽고 싶다면** (쪽을 더하거나 화질을 바꿀 때)

```bash
python tools/render-textbook.py
```

원본 PDF는 강의 폴더의 `research/` 를 참조합니다. 저작물이라 이 저장소에는 넣지 않습니다.
각 이미지 아래에는 출처와 「무단 배포 금지」가 새겨져 있고, `robots.txt` 로 검색 색인에서 빼 두었습니다.

> ⚠️ **지학사 확인 필요** — 교과서 지면을 공개 주소에 올리는 것이므로, 연수 전에 지학사 쪽 사용 승인을 받아 두시기 바랍니다.
> 더 엄격하게 막아야 한다면 이미지를 Supabase 비공개 버킷으로 옮기고 서명 URL로 내주는 방식으로 바꿀 수 있습니다.

## 5. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 화면이 「불러오지 못했습니다」 | 스키마 SQL을 실행했는지 (2-①) |
| 토글을 켜도 참가자 화면이 안 바뀜 | Realtime에 `settings` 가 들어 있는지 (2-②). 20초마다 자동 재조회하는 안전망이 있어 늦어도 20초 안에는 반영됩니다 |
| 관리자 토글이 "관리자 인증에 실패했습니다" | 브라우저를 새로 열고 `박준일0822` 로 다시 들어가기 |
| 「교과서 보기」를 눌렀는데 빈 화면 | `materials/tb/` 가 배포에 올라갔는지. `python tools/render-textbook.py` 로 다시 굽고 푸시 |
| 현황판 오른쪽 위가 「연결 중…」에서 안 바뀜 | 웹소켓이 막힌 망입니다. 20초 폴링으로 계속 동작하니 그대로 쓰셔도 됩니다 |
